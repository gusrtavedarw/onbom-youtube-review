# 온봄의원 유튜브 100편 검토 HTML

[검토 페이지 열기](https://gusrtavedarw.github.io/onbom-youtube-review/)

사용자가 웹 공개를 요청한 검토용 `index.html`과 화면 표시용 글꼴만 담은 GitHub Pages 저장소입니다. 별도 대본·낭독문·CSV·ZIP 파일은 이 저장소에 포함하지 않습니다. 원본 파일 링크는 기존 비공개 저장소로 연결됩니다.

`main` 루트에서 배포하며 `.nojekyll`로 정적 HTML을 그대로 제공합니다. 100편은 페이지의 **전체 100편** 필터에서 볼 수 있습니다.

Pretendard 글꼴은 SIL Open Font License 1.1을 따릅니다. `assets/Pretendard-LICENSE.txt`를 참고하세요.
